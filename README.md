# 🗓️ Plan Zajęć — szkoła podstawowa specjalna

Prosta aplikacja w przeglądarce (PWA) do układania tygodniowych planów zajęć — w stylu FET, ale uproszczona i szybsza w obsłudze.

## Funkcje
- **Dane** — oddziały, nauczyciele, przydziały godzin tygodniowo
- **Automat** — generuje cały plan, pilnując dostępności nauczycieli, limitów dziennych i konfliktów
- **Ręczne poprawki** — przenoszenie i zamiana lekcji z żywą kontrolą konfliktów
- **Godziny lekcyjne** — konfigurowalny rytm dnia (domyślnie: lekcja 45 min)
- **Import** — przydziały wklejone z Worda/Excela (Ctrl+V) lub z pliku CSV/txt
- **Eksport** — plany klas i nauczycieli, CSV do Excela
- **Prywatność** — wszystkie dane zapisują się **wyłącznie lokalnie w przeglądarce** (localStorage). Aplikacja nie wysyła niczego na serwer, a to repozytorium zawiera tylko kod — bez żadnych danych.

## Uruchomienie
